# Збирач цін

Відкриває сторінки конкурентів у справжньому браузері й віддає їх панелі.

Потрібен лише для магазинів, які не віддають сторінки серверу — зараз це
Сільпо. Решта читається панеллю напряму й без цієї програми.

## Чому саме так

Сільпо стоїть за Cloudflare і відповідає нашому серверу помилкою 403, навіть
на `sitemap.xml`. Той самий запит зі справжнього браузера — зокрема headless,
зокрема з тієї самої мережі — проходить без жодної перевірки. Тобто справа не
в адресі й не в машині, а в тому, чи це браузер.

Збирач нічого не розбирає: він відкриває сторінку й надсилає готовий HTML.
Зіставлення назв, вибір потрібної позиції та перерахунок за кілограм лишаються
в панелі — інакше цю логіку довелося б тримати однаковою у двох місцях.

## Встановлення

```bash
cd collector
npm install
npm run setup          # завантажує Chromium, ~150 МБ, один раз
```

## Запуск

```bash
APP_URL=https://hs-merchant.vercel.app \
COLLECTOR_KEY=<ключ із панелі> \
npm start
```

Програма працює постійно: раз на хвилину питає панель, чи є сторінки для
відкриття. Коли їх немає — нічого не робить і майже не споживає ресурсів.

## Де його тримати

Підійде будь-яка машина з інтернетом, яка ввімкнена о 9:30:

- **офісний комп'ютер** — найпростіше, нічого купувати не треба;
- **міні-ПК або Raspberry Pi** в офісі — ~2 Вт, вмикається раз і працює;
- **звичайний VPS** — теж працює: перевірка Cloudflare проходиться браузером,
  а не адресою. Якщо конкретний сайт усе ж почне питати — перенесіть збирач
  в офісну мережу.

Щоб працював як служба на Linux:

```ini
# /etc/systemd/system/hs-collector.service
[Unit]
Description=HS price collector
After=network-online.target

[Service]
WorkingDirectory=/opt/hs-collector
Environment=APP_URL=https://hs-merchant.vercel.app
Environment=COLLECTOR_KEY=...
ExecStart=/usr/bin/node index.js
Restart=always
RestartSec=30

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now hs-collector
```

## Змінні

| Змінна | Що робить |
|---|---|
| `APP_URL` | адреса панелі |
| `COLLECTOR_KEY` | ключ, виданий у панелі |
| `POLL_SECONDS` | як часто питати завдання, за замовчуванням 60 |
| `HEADFUL=1` | показувати вікно браузера — для налагодження |

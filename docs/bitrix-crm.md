# Бітрікс: що де лежить

Портал `crm.halytska-svizhyna.ua` (коробковий Бітрікс24). Замовлення з сайту —
воронка **category 1 «Замовлення з НОВОГО САЙТУ»**. Зібрано з інтерфейсу
19.10.2026; коди полів і стадій узяті з самої сторінки, не з документації.

## Стадії (`STAGE_ID`)

| Стадія | Код |
|---|---|
| Очікування оплати | `C1:NEW` |
| В обробці | `C1:PREPARATION` |
| Комплектується | `C1:PREPAYMENT_INVOICE` |
| Спаковано | `C1:FINAL_INVOICE` |
| В дорозі | `C1:1` |
| В обробці (списано кошти) | `C1:EXECUTING` |
| ПЕРЕДЗАМОВЛЕННЯ | `C1:2` |

Плюс службові `C1:WON` (успішна), `C1:LOSE` (провалена), `C1:APOLOGY`.

Назви оманливі: «Комплектується» має код рахунку-передоплати, «Спаковано» —
код фінального рахунку. Це наслідок того, що воронку зібрали з типових стадій,
перейменувавши їх. Орієнтуватись треба на код, не на назву.

## Поля угоди

| Наше | Код у Бітріксі | Тип |
|---|---|---|
| Склад | `UF_BILL_ADRESS_LIST` | iblock_element — пише **ID елемента**, не назву |
| Період доставки | `UF_CRM_1606047143435` | enum: `26` = 11:00-14:00, `27` = 14:00-17:00, `345` = 17:00-20:00 |
| Дата доставки | `UF_CRM_1606047095` | date |
| Адреса | `UF_CRM_1606294264905` | string («Адреса з сайту») |
| Тип оплати | `UF_PAYMANT_TYPE` | enum: `173` готівка, `174` картка курʼєру, `175` iPay, `427` передоплата |
| Тип доставки | `UF_SHIPPING` | enum: `176` доставка, `177` самовивіз, `425` Нова Пошта |
| Інший отримувач | `UF_DEST_PERSONA` | string |
| Вартість доставки | `UF_DELIVERY_COAST` | string |
| Номер ящика | `UF_CRM_1607510002583` | string |
| Зона доставки | `UF_DELIVERY_ZONE_LIST` | iblock_element |
| Ключ замовлення з сайту | `UF_ORDER_KEY`, `UF_ORIGIN_ID` | string / double |

Три наші періоди доставки збігаються з першими трьома значеннями поля — те
саме вікно, той самий поділ.

## Склади (`UF_BILL_ADRESS_LIST`, інфоблок 31)

Поле приймає ID елемента довідника, не назву. Усі сім складів із наших зон
доставки в довіднику є, назви збігаються символ у символ:

| Склад | ID | Зона |
|---|---|---|
| Гуртівня онлайн | `7272` | zone_2 |
| АС 2 онлайн | `7273` | zone_1, zone_8 |
| Санта онлайн | `7433` | zone_7 |
| М 10 онлайн | `7434` | zone_3 |
| МЕ ТТ Іскра | `11974` | zone_5 |
| МЕ ЦУМ онлайн | `12456` | zone_6 |
| МЕ Панська Гора Онлайн | `18256` | zone_4 |

У довіднику є ще «Асортимент онлайн» (7341) і «МЕ Поштомат онлайн» (15052) —
у наших зонах вони не трапляються.

Зони доставки лежать в окремому полі `UF_DELIVERY_ZONE_LIST` (інфоблок 23).

Довідник читається так: `lists.element.get?IBLOCK_TYPE_ID=lists&IBLOCK_ID=31`,
по 50 елементів на сторінку.

## Доступ

Ключ — вхідний вебхук **ID 28** (права власника, тобто на весь портал, не лише
на CRM). Лежить у змінній `BITRIX_WEBHOOK_URL` на Vercel. Акаунт не адмін CRM:
нові користувацькі поля створити звідси не вийде, потрібні — уже є.
